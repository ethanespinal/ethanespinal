## 🚀 Featured Projects

### [Autonomous Boat Navigation System](https://github.com/ethanespinal/autonomous-boat-navigation)

ESP32-based autonomous boat that navigates a four-waypoint course using **MQTT localization, PID control, and MPU6050 IMU feedback**.

- Developed C++ navigation and control firmware for the ESP32
- Processed real-time position and heading data over MQTT
- Used PID control and IMU feedback to reduce drift during navigation
- Completed three autonomous laps in approximately 4.5 minutes

### [Kona Kalc](https://github.com/ethanespinal/kona-kalc)

Python CLI tool that calculates departure times for mobile vending shifts based on travel time, preparation time, and scheduling constraints.
